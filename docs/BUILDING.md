# Building from source

Prebuilt binaries do not need any of this. You only need a Rust toolchain
to build lasrs-cpp itself from source.

## Requirements

| Tool | Version | Notes |
|---|---|---|
| Rust (rustup) | pinned by `rust-toolchain.toml` | installs `rustc` and `cargo` |
| CMake | 3.22+ | |
| C++ compiler | C++17 | MSVC 2019+, GCC 9+, Clang 10+ |
| Ninja | any | optional, faster builds |

### Windows

```
winget install Rustlang.Rustup
winget install Kitware.CMake
winget install Ninja-build.Ninja
```

Use the default `x86_64-pc-windows-msvc` Rust toolchain. Open a new
terminal afterwards so PATH is updated.

### Linux / macOS

```
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```

Install CMake and a C++ compiler with your package manager.

## Build

```
cmake --preset release
cmake --build --preset release
ctest --preset release
```

The first build downloads Corrosion and the Rust crates and compiles them;
later builds are incremental.

## Using from another CMake project

```cmake
include(FetchContent)
FetchContent_Declare(lasrs
  GIT_REPOSITORY https://github.com/<owner>/lasrs-cpp.git
  GIT_TAG vX.Y.Z)
FetchContent_MakeAvailable(lasrs)

target_link_libraries(my_app PRIVATE lasrs::lasrs)
```

## Regenerating the C header

The C header `include/lasrs/lasrs.h` is generated by cbindgen and
committed. After changing exported Rust functions:

```
cargo install cbindgen
cbindgen --config rust/cbindgen.toml --crate lasrs_ffi --output include/lasrs/lasrs.h rust
```

CI fails if the committed header is out of date.
