# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Everyone taking part in the project's issues, pull requests and discussions
is expected to follow it. Report unacceptable behavior to the maintainer,
[@bloom256](https://github.com/bloom256), for example through a private
vulnerability report or GitHub's report-abuse feature; reports are handled
confidentially.
